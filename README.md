# Task Manager (Minecraft Edition)

A standalone campus micro-task manager built as a single-file web app, split into a cleaner repository structure while preserving the original behavior and code.

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` – page structure and app layout
- `styles.css` – all Minecraft-themed styling
- `script.js` – state, rendering logic, audio effects, and interactions

## Notes

This is intentionally organized as a static front-end app, matching the original implementation without changing the functionality.
